# The Divine

Static, multi-page website for The Divine Unisex Salon in Sripally, Bardhaman. Built with HTML, CSS, and JavaScript for GitHub Pages; no build step or framework is needed.

## Pages

Home, About, Services, Hair & Grooming, Skin & Facials, Gallery, Reviews, FAQ, and Contact. The Contact form prepares a WhatsApp message in the visitor's browser; it does not store or submit data to a server.

## Publishing

Enable GitHub Pages on the `main` branch at the repository root. The website is configured for `https://cloudempiretech.github.io/TheDivine/` in canonical URLs, structured data, `sitemap.xml`, and `robots.txt`. If the final domain changes, update these URLs on every page and in both SEO files before publishing.
